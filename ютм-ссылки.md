# UTM-ссылки на форму записи

База: `https://formareg.brandgrossmeister.ru/`

Форма ловит метки из URL, сохраняет их на время сессии и присылает в Telegram-уведомление
строкой **«📈 Источник (UTM)»**, чтобы было видно, откуда пришла заявка.

| Источник | Ссылка |
|----------|--------|
| Мой ВК | https://formareg.brandgrossmeister.ru/?utm_source=vk&utm_medium=social |
| Жукова | https://formareg.brandgrossmeister.ru/?utm_source=zhukova&utm_medium=referral |
| Мой Telegram | https://formareg.brandgrossmeister.ru/?utm_source=telegram&utm_medium=messenger |
| Мой MAX | https://formareg.brandgrossmeister.ru/?utm_source=max&utm_medium=messenger |
| Инстаграм | https://formareg.brandgrossmeister.ru/?utm_source=instagram&utm_medium=social |
| Конференция Маровой | https://formareg.brandgrossmeister.ru/?utm_source=marova&utm_medium=conference |
| Тесты | ✓ проверила — https://formareg.brandgrossmeister.ru/?utm_source=test&utm_medium=test |

## Тест «Джонатан Ливингстон» (одна ссылка)

Единая ссылка на кампанию без привязки к соцсети — в Telegram будет строка
`источник: jonathan_livingston, кампания: jonathan_livingston`, по ней видно заявки именно этого теста.

```
https://formareg.brandgrossmeister.ru/?utm_source=jonathan_livingston&utm_campaign=jonathan_livingston
```

## AI-агент по «Чайке»

Ссылка для заявок из AI-агента — в Telegram будет строка
`источник: ai_agent, канал: ai, кампания: chaika`.

```
https://formareg.brandgrossmeister.ru/?utm_source=ai_agent&utm_medium=ai&utm_campaign=chaika
```

## Как это выглядит в Telegram

Например, по заявке с ссылки Жуковой в уведомлении будет строка:

```
📈 Источник (UTM): источник: zhukova, канал: referral
```

## Параметры

- `utm_source` — кто/где (vk, instagram, zhukova, telegram, max, marova, test)
- `utm_medium` — тип канала (social, referral, messenger, conference, test)
- При желании можно добавить `utm_campaign` и `utm_content` — они тоже попадут в уведомление.

> Метки чувствительны к регистру и должны быть без пробелов. Менять/добавлять ссылки можно
> прямо здесь — они нигде в коде не «зашиты», форма принимает любые значения utm_*.
