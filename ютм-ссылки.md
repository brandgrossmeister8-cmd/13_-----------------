# UTM-ссылки на форму записи

База: `https://formareg.brandgrossmeister.ru/`

Форма ловит метки из URL, сохраняет их на время сессии и присылает в Telegram-уведомление
строкой **«📈 Источник (UTM)»**, чтобы было видно, откуда пришла заявка.

| Источник | Ссылка |
|----------|--------|
| Мой ВК | https://formareg.brandgrossmeister.ru/?utm_source=vk&utm_medium=social |
| Жукова | https://formareg.brandgrossmeister.ru/?utm_source=zhukova&utm_medium=referral |
| Мой Telegram | https://formareg.brandgrossmeister.ru/?utm_source=telegram&utm_medium=messenger |
| Мой MAX | https://formareg.brandgrossmeister.ru/?utm_source=max&utm_medium=messenger |
| Тесты | https://formareg.brandgrossmeister.ru/?utm_source=test&utm_medium=test |

## Как это выглядит в Telegram

Например, по заявке с ссылки Жуковой в уведомлении будет строка:

```
📈 Источник (UTM): источник: zhukova, канал: referral
```

## Параметры

- `utm_source` — кто/где (vk, zhukova, telegram, max, test)
- `utm_medium` — тип канала (social, referral, messenger, test)
- При желании можно добавить `utm_campaign` и `utm_content` — они тоже попадут в уведомление.

> Метки чувствительны к регистру и должны быть без пробелов. Менять/добавлять ссылки можно
> прямо здесь — они нигде в коде не «зашиты», форма принимает любые значения utm_*.
